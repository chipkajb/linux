NOTIFICATIONS & QUICK NAV
──────────────────────────────────────────────────────────────────────────────────────
  q         toggle notification quiet mode — *Q*uiet
  x         pop last dismissed notification (dunst history)
  z         goto latest dunst notification workspace
  y         move window to overflow (9) and go there

  Tab       workspace back and forth
  u         next workspace
  .*        focus window content (emulates mouse click)

  i         show this hotkey help — *I*nformation


WORKSPACES
──────────────────────────────────────────────────────────────────────────────────────
  1 – 9, 0      switch to workspace 1 – 10
  1* – 9*, 0*   move focused window to workspace 1 – 10

  1   🌍 Web
  2   ⚫ Terminal
  3   💻 Code
  4   💬 Messages
  5   📁 Files
  6   📝 Notes
  7   🎵 Music
  8   🤖 Claude
  9   🔀 Overflow
  10  💾 Database


WINDOW FOCUS & MOVE
──────────────────────────────────────────────────────────────────────────────────────
  h j k l           focus left / down / up / right
  arrow keys        focus left / down / up / right

  h* j* k* l*       move window left / down / up / right
  arrow*            move window left / down / up / right


LAYOUT & RESIZE
──────────────────────────────────────────────────────────────────────────────────────
  e           layout toggle split
  e*          logout — *E*xit
  f           fullscreen toggle — *F*ull screen
  v           split vertically
  ;           split horizontally
  space       toggle floating / tiling
  space*      focus tiling / floating windows
  r           resize mode — *R*esize (Esc, Enter, or r to exit)
  r*          restart i3 — *R*estart


LAUNCHERS (ROFI)
──────────────────────────────────────────────────────────────────────────────────────
  w           window switcher
  s*          ssh host switcher — *S*SH (~/.ssh/config)


SCRATCH & TERMINAL
──────────────────────────────────────────────────────────────────────────────────────
  t           obsidian notes scratch (vim in vault) — *T*ext editor
  Enter       open terminal (Herdr)


MONITORS
──────────────────────────────────────────────────────────────────────────────────────
  ,           move workspace to output left
  .           move workspace to output right
  =           move workspace to output up
  -           move workspace to output down


SYSTEM
──────────────────────────────────────────────────────────────────────────────────────
  c*          reload i3 configuration — *C*onfiguration
  q*          quit focused window — *Q*uit
  x*          lock screen


NOTIFICATIONS (ALT)
──────────────────────────────────────────────────────────────────────────────────────
  Alt+r         close most recent notification
  Alt+Space     close all notifications


MEDIA KEYS
──────────────────────────────────────────────────────────────────────────────────────
  Volume Up / Down     raise / lower volume
  Volume Mute          toggle mute
  Mic Mute             toggle microphone mute
